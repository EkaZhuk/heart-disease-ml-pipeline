# Model Card: Heart Disease Prediction

## Model Details

- **Developed by:** Сидоров Павел, Сидорова Екатерина
- **Model date:** 2026
- **Model version:** 1.0
- **Model type:** Бинарная классификация (RandomForestClassifier)
- **License:** Учебный проект
- **Где используется:** в AutoML-пайплайне `src/automl_pipeline.py`

**Описание:** модель предсказывает наличие сердечно-сосудистого заболевания
по 13 клиническим показателям (возраст, пол, тип боли в груди, давление,
холестерин, ЭКГ-показатели и др.).

---

## Intended Use

### Основное назначение

**Скрининговый инструмент** для выявления **риска** сердечно-сосудистых
заболеваний на основе табличных клинических данных. Модель **не заменяет
врача** и не ставит диагноз — она даёт **второе мнение**.

### Целевые пользователи

- Врачи-кардиологи — для **поддержки** принятия решений
- Исследователи — для **демонстрации** ML-подхода
- Студенты — как **учебный** пример AutoML-пайплайна

### Out-of-Scope Use (где НЕ использовать)

- ❌ Экстренная триажа (сортировка пациентов в неотложке)
- ❌ Постановка **окончательного** диагноза
- ❌ Назначение лечения или дозировок
- ❌ Пациенты с отсутствующими признаками (`ca`, `thal`, `oldpeak`)
- ❌ Дети и подростки (датасет обучался на взрослых 29–77 лет)
- ❌ Беременные (в датасете нет таких данных)

## Training Data

| Параметр | Значение |
|----------|----------|
| Источник | [Kaggle Heart Disease Dataset](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset) |
| Размер | 1025 строк, из них 723 полных дубликата; после очистки **302 записи** |
| Признаков | 13 + target |
| Целевая переменная | `target` (0 — нет заболевания, 1 — есть) |
| Распределение классов | 499 (1) / 526 (0) до очистки; 138 (1) / 164 (0) после очистки |
| Кодировка `target` | В исходном файле значения перепутаны (среднее `ca` при 1 равно 0.34, при 0 — 1.17). В проекте они переворачиваются настройкой `invert_target` |
| Пропуски | Нет |
| Оригинал | UCI Heart Disease (Cleveland, около 300 записей), размножен копиями строк |

**Признаки:** `age`, `sex`, `cp`, `trestbps`, `chol`, `fbs`, `restecg`,
`thalach`, `exang`, `oldpeak`, `slope`, `ca`, `thal`.

## Performance Metrics

### Test set (61 запись, 20%)

| Метрика | Значение |
|---------|----------|
| Accuracy | 0.803 |
| Precision | 0.767 |
| Recall | 0.821 |
| F1-Score | 0.793 |
| ROC-AUC | 0.890 |

Матрица ошибок на тесте: верно определены 23 больных и 26 здоровых,
**5 больных пропущено**, 7 здоровых ошибочно названы больными.

### Кросс-валидация (StratifiedKFold, 5 фолдов, 241 запись)

| Метрика | Значение |
|---------|----------|
| CV Accuracy (mean) | **0.8463** |
| CV Accuracy (std) | 0.0369 |

**Важно:** до удаления дубликатов модель показывала Accuracy 1.00 на тесте и
0.99 на кросс-валидации. Причиной была **утечка данных**: 723 из 1025 строк
были копиями, и одна и та же запись попадала и в обучение, и в тест. После
очистки реальная оценка качества составляет **0.80–0.85**.

Кросс-валидационная оценка немного завышена: на тех же фолдах подбирались
гиперпараметры и выбиралась лучшая модель.

### Сравнение моделей

| Модель | CV Accuracy | Test Accuracy | Precision | Recall | F1-Score |
|--------|-------------|---------------|-----------|--------|----------|
| **RandomForest** | **0.846** | **0.803** | **0.767** | **0.821** | **0.793** |
| SVM | 0.838 | 0.803 | 0.808 | 0.750 | 0.778 |
| LogisticRegression | 0.834 | 0.787 | 0.778 | 0.750 | 0.764 |
| GradientBoosting | 0.813 | 0.787 | 0.800 | 0.714 | 0.755 |

Модель выбирается автоматически по CV Accuracy. Разница между моделями
меньше разброса кросс-валидации (0.04), поэтому их порядок ненадёжен.

## Known Limitations

1. **Датасет размножен копиями строк:** из 1025 строк уникальных только 302.
   Для обучения осталась 241 запись, для теста — 61.
2. **Нет внешней валидации** — модель проверена только на своих данных.
   На другом госпитале точность может **упасть до 50–70%**.
3. **Только табличные признаки** — не учитывает ЭКГ-сигналы, тропонин,
   УЗИ, МРТ, историю болезни.
4. **Ограниченная популяция** — обучена на взрослых 29–77 лет, преимущественно
   из одной клиники (Cleveland).
5. **Подозрительные значения:** в данных есть `ca` = 4 и `thal` = 0 при шкалах
   0–3 и 1–3. Вероятно, так закодированы пропуски.
6. **Маленький тест (61 запись):** разница между моделями составляет
   несколько записей, поэтому метрики сильно зависят от случайного разбиения.
7. **Нет калибровки вероятностей** — `predict_proba` может быть смещён.

## Ethical Considerations

- **Не для диагностики.** Модель — **вспомогательный** инструмент. Решение
  принимает **врач**.
- **Риск ошибки.** Около 20% ответов на тесте неверны, 5 из 28 больных
  пропущено. Модель нельзя считать надёжной — см. ограничения выше.
- **Предвзятость.** Датасет из одной клиники → модель может быть **предвзята**
  к другим этническим и возрастным группам.
- **Приватность.** Датасет анонимизирован, но модель обучена на конкретных
  пациентах — **не выкладывайте `heart.csv` в публичный доступ**.
- **Ответственность.** Разработчики **не несут** ответственности за решения,
  принятые на основе модели.

## Caveats

Модель демонстрирует **учебный** AutoML-пайплайн. Для реального клинического
применения требуется:

1. **Внешняя валидация** на нескольких госпиталях
2. **Проверка на подгруппах** (возраст, пол, этнос)
3. **Калибровка вероятностей** (Platt scaling, isotonic regression)
4. **Регуляторное одобрение** (FDA, Минздрав)
5. **Мониторинг дрейфа** данных в продакшене
6. **Аудит предвзятости** (fairness audit)

```
Данные → Предобработка → AutoML (4 модели) → RandomForest → Сохранение → Использование
                                                    ↑
                                              ЭТА МОДЕЛЬ
```

**Как используется:**
- Обучается в `src/automl_pipeline.py`
- Сохраняется в `models/heart_disease_model.pkl`
- Скалер — в `models/scaler.pkl`
- Метрики — в `results/model_comparison.csv`
